# 已知限制

各项对应的计划见 [路线图](../ROADMAP.md)。

## 验证缺口

- **还没有用真实模型做端到端验证**：真实的流式请求、跨域请求、带页面工具的多轮对话都待验证。
- **原生站点授权弹窗仍需手动验证**：自动测试覆盖未授权请求被拒绝，以及按钮在点击时同步请求正确的权限；接受弹窗后的正式版完整流程不由自动测试覆盖。
- 未验证：Firefox 侧边栏关闭后长时间运行的任务；chord 的心跳是否会让 SW 一直不休眠。

## 功能缺口

- 不支持图片输入和附件。
- 面板不分页加载更早的历史，只显示 Durable view 窗口内的记录。
- 没有 Linux 沙箱或 shell，文件处理交给 Code Mode；文件系统不支持符号链接、gitignore 或变更通知。
- Fetch 不带登录态，也不跟随重定向，需要这些能力的网站暂不支持。

## 数据与平台

- 移除对话会停止运行、清除文件并从列表移除；Durable 的对话记录仍保留，因为 pi-durable 1.5 没有删除对话的接口。
- 文件总容量受浏览器配额限制，尚无每对话总量限制或临时文件定期清理；Firefox 事件页回收后的文件流程未专门测试。
- Chromium 上 offscreen 文档空闲时不会自动关闭。
- Firefox 附加组件 ID `oshawatt@example.org` 是占位值；AMO 要求的 `data_collection_permissions` 和相应同意流程尚未完成。数据说明见[隐私政策草稿](../PRIVACY.md)，发布要求见[开发](development.md#发布前清单)。
