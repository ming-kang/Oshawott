# 已知限制

## 尚未验证

- 真实模型的流式请求、跨域请求，以及带页面工具的多轮对话。
- 站点授权弹窗的完整流程（允许、拒绝、撤销授权）；目前自动测试只覆盖拒绝未授权请求和授权按钮。
- Firefox 关闭侧边栏后的长时间任务、事件页被回收后的文件操作，以及 chord 心跳对 Chromium Service Worker 休眠的影响。

## 当前限制

- 不支持图片输入和附件；Panel 只显示 Durable view 窗口内的记录，不能加载更早的历史。
- fetch 不带登录态，也不跟随重定向。
- 移除对话后，Durable 中的原始对话记录仍会保留（pi-durable 1.5 没有删除接口）。
- 没有单个对话的配额限制，也不会定期清理临时文件。
- Chromium 的 offscreen 文档空闲时不会自动关闭。
