# 已知限制

## 尚未验证

- 真实模型的流式请求、跨域请求和带页面工具的多轮对话。
- 原生站点授权弹窗的接受、拒绝与撤权完整流程；自动测试只覆盖拒绝未授权请求和权限按钮行为。
- Firefox 侧边栏关闭后的长时间任务、事件页回收后的文件流程，以及 chord 心跳对 Chromium Service Worker 休眠的影响。

## 当前限制

- 不支持图片输入和附件；Panel 不分页加载更早历史，只显示 Durable view 窗口内的记录。
- fetch 不带登录态、不跟随重定向。
- 移除对话会停止运行并清除文件，但 pi-durable 1.5 没有删除原始对话记录的接口。
- 文件总容量受浏览器配额限制，尚无每对话配额或临时文件定期清理。
- Chromium offscreen 文档空闲时不会自动关闭。
